# CSSHARK — portfolio

A responsive, bilingual (Polish/English) cybersecurity portfolio for Robert Strzoda (`csshark`), built with plain HTML, CSS and JavaScript for GitHub Pages.

## Files

- `index.html` — page structure and portfolio content
- `styles.css` — responsive editorial design, dark palette and visual effects
- `script.js` — language switcher and mobile navigation
- `assets/` — place your own photos or media here

## Publish to GitHub Pages

1. Create or open the repository named **`csshark.github.io`**.
2. Upload the contents of this folder to the repository root (so `index.html` is at the root).
3. Commit and push to the default branch.
4. In GitHub, open **Settings → Pages**.
5. Under **Build and deployment**, select **Deploy from a branch**, choose your default branch and `/ (root)`, then save.
6. Wait for the Pages deployment to complete and open the published URL.

GitHub's official guide: https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site

## Personalise before publishing

- Replace the Physical Red Teaming placeholder panel with a photo you have permission to publish. Add the image to `assets/` and update the panel in `index.html`.
- Add the public article URL for Black Hat Ethical Hacking coverage of FormPoison when you have the exact link.
- Add public event pages, slide decks or recordings for MSHP 2026, THS 2026 and OffSec Warsaw Chapter 0x03 when available.
- Review dates and wording in the timeline to make sure they match your intended chronology.
- If you prefer not to publish your email address, replace the `mailto:` link with a contact form provider or remove it.
- Check all claims and links before publishing. Public GitHub Pages sites are accessible on the internet.
